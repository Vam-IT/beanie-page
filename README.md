# CupTrail Website

Eine moderne, animierte und optimierte Website für **CupTrail** – die smarte Kaffee- und Koffein-Tracking App für iPhone (ab iOS 17.0) und Apple Watch (ab watchOS 10.0), bereitgestellt von der VAMIT UG (haftungsbeschränkt).

## 🚀 Technologie-Stack

- **React 19** - UI-Framework
- **Vite 7** - Build-Tool & Dev-Server
- **Tailwind CSS** - Styling mit speziellem Dark-Roast & Coffee-Designsystem
- **Framer Motion** - Animationen, Parallax und sanfte Übergänge
- **React Router** - Client-Side Routing für Startseite, Datenschutz, Nutzungsbedingungen & Impressum
- **Lucide React** - Moderne Icons
